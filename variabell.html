D. Apersepsi

Pertanyaan: Bagaimana cara menyimpan informasi siswa di dalam program?

Informasi siswa dapat disimpan menggunakan variable. Setiap variable mempunyai nama dan nilai untuk menyimpan data seperti nama, kelas, umur, dan nilai siswa. 
let nama = "Risanda";
let kelas = "X PPLG 2";
let umur = 15;
let nilai = 85;

E. Aktivitas 1 — Mengamati

let nama = "Risanda";
let umur = 15;
let nilai = 85;

console.log(nama);
console.log(umur);
console.log(nilai);

1. Apa yang ditampilkan pada Console?

Risanda
15
85

2. Apa fungsi nama, umur, dan nilai?

Nama, umur, dan nilai adalah variable yang digunakan untuk menyimpan data. Variable nama menyimpan teks Risanda, umur menyimpan angka 15, dan nilai menyimpan angka 85.

3. Apa yang terjadi jika console.log(nama) dijalankan?

Console menampilkan nilai yang tersimpan dalam variable nama, yaitu Risanda.

4. Apa yang dimaksud dengan variable?

Variable adalah tempat untuk menyimpan data agar data tersebut dapat digunakan kembali oleh program.

H. Aktivitas 4 — Eksperimen

1. Apakah hasil pada Console berubah?

Ya, hasil Console berubah sesuai nilai baru yang dimasukkan ke dalam variable.

2. Bagian kode mana yang diubah?

Nilai pada variable nama, kelas, dan umur.

3. Mengapa program dapat menampilkan data yang baru?

Karena program membaca nilai yang tersimpan pada variable. Setelah nilainya diubah, program menampilkan nilai yang baru.
Ganti data contoh dengan nama, kelas, dan umur kamu sendiri.

I. Aktivitas 5 — Berbagai Jenis Data

let nama = "Risanda";
let umur = 15;
let tinggi = 140;
let aktif = true;
Variable Nilai Jenis Data
nama "Risanda" String (teks)
umur 15 Number (angka)
tinggi 140 Number (angka)
aktif true Boolean (benar atau salah)

Kesimpulan

Data yang ditulis menggunakan tanda kutip seperti "Risanda" merupakan data String atau teks. Sedangkan 15 merupakan data Number atau angka.

J. Aktivitas 6 — Mengenal let dan const

Contoh penggunaan let

let umur = 16;
umur = 17;
console.log(umur);
Hasilnya adalah 17 karena nilai variable yang menggunakan let dapat diubah.

Contoh penggunaan const

const nama = "Budi";
nama = "Andi";
console.log(nama);
Program menghasilkan error karena variable const tidak dapat ditetapkan ulang. Baris yang mengubah nama harus dihapus jika ingin program berjalan tanpa error.
Keyword Nilai dapat diubah? Kegunaan
let Ya Untuk data yang masih mungkin berubah.
const Tidak dapat ditetapkan ulang Untuk data yang tidak perlu ditetapkan ulang.

O. Aktivitas 11 — Debugging

Program yang sudah diperbaiki:

let namaSiswa = "Risanda";
let umur = 15;
let kelas2 = "X PPLG 2";

console.log(namaSiswa);
console.log(umur);
console.log(kelas2);

Kesalahan yang ditemukan

  1. nama siswa salah karena mengandung spasi. Diperbaiki menjadi namaSiswa.
  2. 2kelas salah karena nama variable tidak boleh diawali angka. Diperbaiki menjadi kelas2.
  3. Nama variable di console.log() harus sama dengan nama variable yang dideklarasikan.

Q. Aktivitas 13 — Think Pair Share

Think: Mengapa programmer membutuhkan variable?

Programmer membutuhkan variable untuk menyimpan dan mengelola data agar dapat digunakan kembali, ditampilkan, atau diolah oleh program.

Pair: Apakah jawaban kalian sama?

Contoh jawaban: Ya, jawaban kami hampir sama karena kami memahami bahwa variable digunakan untuk menyimpan data.

Jika berbeda, apa perbedaannya?

Contoh jawaban: Perbedaannya terdapat pada contoh. Saya mencontohkan nama dan umur, sedangkan teman saya mencontohkan nilai dan kelas.

Variable membantu program menyimpan data dengan nama tertentu agar mudah dipanggil dan digunakan kembali.
